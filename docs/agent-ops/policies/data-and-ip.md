# Policy: data & IP

- **M0** frozen snapshot: allowed for demo/search.
- **M1** allowlisted agent thin crawl: escalate to Bob before enabling.
- **M2** partner feed: preferred; draft-first deploy of new corpus.
- **M3** fat YOH/Rightmove-style rescrape for public mirror: **forbidden** without written Bob approval.
- Public surfaces stay **thin** (snippet + outbound). No full description dump as destination.
- Country guides: original modules + attributed further-reading. Never scrape-republish Lumon/YOH guide bodies.
- Canonical URL must be absolute; prefer agent-direct sources when available.
