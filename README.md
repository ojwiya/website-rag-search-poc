# website-rag-search-poc

RAG-powered property search web app MVP with improved UI/UX based on youroverseashome.com design.

- **RAG:** Reuses the existing `rag-property-search-poc` pipeline (scraping, ingestion, vector search) — no rescraping.
- **Frontend:** Fast JavaScript framework (React/Next.js) with Stripe-inspired design system.
- **Deploy:** Vercel (frontend + serverless API).
- **Design:** claude-design process + popular-web-designs Stripe template, with the reference site's blue/white/gray palette preserved.
